## Implementation Details

### HTML Attribute Strategy
```html
<!-- Text content -->
<span data-i18n="message_key"></span>

<!-- Input placeholders -->
<input data-i18n-placeholder="placeholder_key" />

<!-- Button text -->
<button data-i18n="button_key"></button>

<!-- Aria labels -->
<div data-i18n-aria-label="aria_key"></div>
```

### TypeScript Helper Usage
```typescript
import { t } from '../i18n';

// Simple message
element.textContent = t('simple_message');

// With placeholders  
element.textContent = t('welcome_message', [username]);

// Error handling
try {
  const message = t('error_message');
} catch (error) {
  console.warn('Missing translation:', error);
  element.textContent = 'An error occurred';
}
```

### Localization Function Structure
```typescript
function localizeHTML(): void {
  // Text content localization
  document.querySelectorAll('[data-i18n]').forEach(element => {
    const key = element.getAttribute('data-i18n');
    if (key) element.textContent = t(key);
  });
  
  // Placeholder localization
  document.querySelectorAll('[data-i18n-placeholder]').forEach(element => {
    const key = element.getAttribute('data-i18n-placeholder');
    if (key && element instanceof HTMLInputElement) {
      element.placeholder = t(key);
    }
  });
}
```
