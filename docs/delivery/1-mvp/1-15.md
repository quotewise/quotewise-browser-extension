# 1-15 Migrate API endpoints to v2

[Back to task list](./tasks.md)

**Parent PBI**: [PBI 1: MVP Chrome Extension](./prd.md)

## Description

Migrate all API client calls from Quotosaurus/Quotewise API v1 endpoints to v2. The v2 API uses cleaner RESTful patterns, proper HTTP verbs, and introduces new capabilities. This task ensures the Chrome extension uses the current API version.

## Requirements

### Functional Requirements

**Collection Endpoints Migration**:

| Operation | v1 Endpoint | v2 Endpoint | Method |
|-----------|-------------|-------------|--------|
| Collect quote to default | POST /api/v1/quotes/collect/ | POST /api/v2/collections/{slug}/quotes/ | POST |
| Discard quote | POST /api/v1/collections/quotes/discard/ | DELETE /api/v2/collections/{slug}/quotes/{quote_id}/ | DELETE |
| Discard quote (with ID) | POST /api/v1/collections/quotes/{quote_id}/discard/ | DELETE /api/v2/collections/{slug}/quotes/{quote_id}/ | DELETE |
| Create collection | POST /api/v1/collections/ | POST /api/v2/collections/ | POST |
| List collections | GET /api/v1/collections/list/ | GET /api/v2/collections/ | GET |
| Check name available | POST /api/v1/collections/check-name/ | POST /api/v2/collections/check_name/ | POST |
| Update collection | PUT /api/v1/collections/{slug}/update/ | PUT /api/v2/collections/{slug}/ | PUT |
| Delete collection | DELETE /api/v1/collections/{slug}/delete/ | DELETE /api/v2/collections/{slug}/ | DELETE |

**Quote Endpoints Migration**:

| Operation | v1 Endpoint | v2 Endpoint | Method |
|-----------|-------------|-------------|--------|
| Check duplicate | POST /api/v1/quotes/check-duplicate/ | POST /api/v2/quotes/check_duplicate/ | POST |
| List/search quotes | N/A | GET /api/v2/quotes/ | GET |
| Get quote details | N/A | GET /api/v2/quotes/{id}/ | GET |
| Similar quotes | N/A | GET /api/v2/quotes/{id}/similar/ | GET |
| Random quotes | N/A | GET /api/v2/quotes/random/ | GET |

**Originator Endpoints Migration**:

| Operation | v1 Endpoint | v2 Endpoint | Method |
|-----------|-------------|-------------|--------|
| Search originators | GET /api/v1/originators/search/ | GET /api/v2/originators/search/ | GET |
| List originators | N/A | GET /api/v2/originators/ | GET |
| Quotes by originator | N/A | GET /api/v2/originators/{id}/quotes/ | GET |
| Similar originators | N/A | GET /api/v2/originators/{id}/similar/ | GET |

**Auth Endpoints Migration**:

| Operation | v1 Endpoint | v2 Endpoint | Method |
|-----------|-------------|-------------|--------|
| Auth status | GET /api/v1/auth/status/ | GET /api/v2/auth/status/ | GET |
| Check username | N/A | GET /api/v2/auth/check_username/ | GET |
| Suggest username | N/A | POST /api/v2/auth/suggest_username/ | POST |

### Non-Functional Requirements

- Maintain backward compatibility during migration if possible
- All existing functionality must continue to work
- No degradation in performance
- Error handling must account for new response formats

### Key Migration Notes

1. **RESTful URLs**: v2 uses clean REST patterns (`/collections/{slug}/` vs `/collections/{slug}/update/`)
2. **Nested resources**: Quotes in collections use `/{slug}/quotes/{id}/` pattern
3. **HTTP verbs**: v2 uses proper verbs (DELETE for removal vs POST)
4. **New features**: v2 adds quote search, similarity, random quotes, originator listing
