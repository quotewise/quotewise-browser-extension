# 1-16 Automatic Originator Lookup by Twitter Handle

[Back to task list](./tasks.md)

**Parent PBI**: [PBI 1: MVP Chrome Extension](./prd.md)

## Description

Add automatic originator lookup by Twitter handle when capturing tweets. When tweet data loads, the extension will call `/api/v1/originators/by-handle/` with the author's Twitter handle. If found, show the originator with an option to auto-populate the selection. If not found, show a status row with "Create on Quotosaurus" link directing users to add the originator on the website.

This reduces friction in the quote capture flow by automating originator discovery and provides a clear path forward when originators don't exist in the system.

## Requirements

### Functional Requirements
- Auto-lookup originator by Twitter handle when tweet data loads (after auth success)
- Display status row below originator search section with lookup progress/results
- If originator found: Show "Found: [Name]" with "Use This Originator" button
- If originator not found: Show "No originator found for @handle" with "Create on Quotosaurus" link
- User can dismiss status row and search manually
- "Use This Originator" auto-populates the originator selection field
- "Create on Quotosaurus" link opens quotosaurus.com with handle pre-filled

### Non-Functional Requirements
- Lookup should complete within 2 seconds under normal network conditions
- Graceful degradation on network errors (allow manual search)
- No lookup if originator already selected

### Integration Requirements
- Use existing `/api/v1/originators/by-handle/` endpoint
- Integrate with existing `OriginatorSearch` component for selection
- Follow existing message passing pattern (popup → service worker → API)

### Key Test Scenarios

1. **Successful Lookup**
   - Given: Tweet data with valid author handle
   - When: Handle lookup is triggered
   - Then: Originator is found and state updates to 'found'

2. **Originator Not Found**
   - Given: Tweet data with unknown author handle
   - When: Handle lookup is triggered
   - Then: State updates to 'not_found' with create_url

3. **Network Error**
   - Given: Network failure during lookup
   - When: Handle lookup is triggered
   - Then: State updates to 'error' with graceful fallback

4. **Use Originator Action**
   - Given: Lookup found an originator
   - When: User clicks "Use This Originator"
   - Then: Originator is auto-selected in the form

5. **Dismiss Action**
   - Given: Lookup result is displayed
   - When: User clicks "Search Manually"
   - Then: Status row is hidden
