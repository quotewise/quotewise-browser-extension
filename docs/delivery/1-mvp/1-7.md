# Task 1-7: Add Duplicate Checking

## Overview
Implement comprehensive duplicate checking functionality that uses the Django API endpoint `/api/v1/quotes/check-duplicate/` to check for similar quotes before submission. The system will provide intelligent recommendations (duplicate, new version, or new quote) with visual feedback and allow users to proceed with submission even when duplicates are found.

## Problem Statement
Users need protection against submitting duplicate quotes while maintaining the flexibility to add legitimate variations or proceed with submissions when appropriate. The duplicate checking system must provide clear recommendations with visual feedback to guide user decisions.

- **Popup UI**: Basic duplicate check button and warning section exist
- **Popup Logic**: `handleDuplicateCheck()` method exists with basic implementation
- **Types**: `DuplicateCheckResult` interface exists but needs updating to match Django API

## Technical Requirements

### API Integration
- **Endpoint**: `/api/v1/quotes/check-duplicate/`
- **Method**: POST
- **Parameters**:
  - `quote_text`: Text content of the quote
  - `originator_id`: ID of the quote originator
  - `source_url`: URL where quote was found (optional)
- **Authentication**: Django session cookies
- **Response Format**:
  ```json
  {
    "recommendation": "duplicate|new_version|new_quote",
    "confidence": 0.95,
    "matches": [
      {
        "quote_id": "uuid",
        "version_id": 123,
        "text": "Similar quote text...",
        "similarity": 0.89,
        "match_type": "exact|semantic|fuzzy",
        "originator": {
          "id": 456,
          "full_name": "Albert Einstein"
        },
        "workflow_status": "approved",
        "likes_count": 42
      }
    ],
    "existing_sightings_for_url": [],
    "reasoning": "High similarity with existing quote...",
    "search_metadata": {}
  }
  ```

### UI/UX Requirements
- **Visual Recommendations**:
  - ✅ **New quote** (green): No duplicates found, safe to submit
  - ⚠️ **New version** (yellow): Similar quote with different originator, review recommended
  - 🚫 **Duplicate** (red): Exact/near match with same originator, submission discouraged
- **Similarity Display**: Show percentage badges (95%+ = exact, 80-94% = very similar, etc.)
- **Match Details**: Expandable view showing original text, originator, status, and like count
- **User Actions**: 
  - View Details: Expand to see all matches
  - Add Anyway: Override duplicate warning with confirmation
  - Edit Quote: Modify text to differentiate
  - Change Originator: Select different attribution
- **Automatic Checking**: Trigger on text/originator changes with 1000ms debounce
- **Loading States**: Show spinner during duplicate checking

## Implementation Details

### Duplicate Check Flow
1. User enters quote text and selects originator
2. Automatic check triggers (debounced) or manual "Check for Duplicates" click
3. API call includes: `quote_text`, `originator_id`, `source_url`
4. API returns recommendation and matches
5. UI updates based on recommendation:
   - **duplicate**: Show red warning, disable submit (can override)
   - **new_version**: Show yellow warning, allow submit
   - **new_quote**: Show green success, allow submit

### Type Definitions Update
