# Task 1-6: Implement Originator Search

## Overview
Implement real-time originator search functionality in the Chrome extension popup that allows users to search for and select quote originators from the Quotewise database.

## Problem Statement
Users need to search for and select the correct originator when capturing quotes. The originator search must provide real-time results with confidence scoring to help users make accurate attributions.

## Technical Requirements

### API Integration
- **Endpoint**: `/api/v1/originators/search/`
- **Method**: GET
- **Parameters**:
  - `q`: Search query (minimum 2 characters)
  - `limit`: Maximum results (default: 10, max: 50)
- **Authentication**: Django session cookies
- **Response Format**:
  ```json
  {
    "results": [
      {
        "id": 123,
        "unique_id": "albert-einstein",
        "full_name": "Albert Einstein", 
        "sort_name_display": "Einstein, Albert",
        "confidence": 8.5
      }
    ]
  }
  ```

### UI/UX Requirements
- **Minimum Query Length**: 2 characters to trigger search
- **Debounce Delay**: 300ms to prevent excessive API calls
- **Search Results**: Display up to 10 results in dropdown
- **Result Display**: Show full name with confidence score
- **Selection**: Click to select, clear selection option
- **Search History**: Show last 5 selected originators for quick access
- **Loading States**: Show spinner during search
- **Error Handling**: Graceful fallback for API errors
