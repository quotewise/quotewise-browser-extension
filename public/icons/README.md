# Extension Icons

This directory contains the extension icons in the required sizes:

- `icon16.png` - 16x16px - Toolbar icon (small)
- `icon48.png` - 48x48px - Extension management page
- `icon128.png` - 128x128px - Chrome Web Store listing

## Icon Requirements

- PNG format
- Square aspect ratio
- Transparent background recommended
- Should represent the Quotewise brand
- Follow Chrome extension icon guidelines

## Current Status

Placeholder icons needed - these should be created by a designer following Quotewise brand guidelines.

For development purposes, you can use simple colored squares or download free icons that represent quotes/text capture.

## Creating Icons

1. Design in vector format (SVG) first
2. Export to PNG at exact required sizes
3. Ensure consistency across all sizes
4. Test visibility at 16px size (most challenging)

## Brand Guidelines

- Should align with Quotewise visual identity
- Consider using quote symbols (") or text-related imagery
- Maintain readability at smallest size
- Use colors that work well on light and dark backgrounds
